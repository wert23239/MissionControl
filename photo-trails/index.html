Importing from Apple Photos

On Mac: select photos → File → Export → Export Unmodified Original. Upload those originals here.

On iPhone: try Choose photos. If locations are missing, export via Share → Options with Location enabled; use All Photos Data when available and save originals to Files.

Screenshots and messaging apps often strip GPS. Missing metadata cannot be reconstructed. HEIC GPS is supported; thumbnail previews depend on your browser.
